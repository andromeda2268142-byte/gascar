# Gas Car's — Expo starter

Initial mobile foundation for Gas Car's using Expo + React Native + TypeScript + Expo Router.

## What is already included

- Universal project for iOS, Android and web
- Explore screen with Gas Car's visual system and DFW demo data
- Request flow foundation
- Garage screen
- Driver profile screen
- Business Portal demo screen
- Environment placeholders for Supabase and Google Maps
- Production identifiers prepared as `com.gascars.app` (can be changed before store release)

## Start locally

1. Install Node.js 22.13+.
2. Run `npm install`.
3. Run `npx expo start`.
4. Open with a development build, Expo Go where compatible, or an emulator/simulator.
